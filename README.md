# UNI2C437
Unicode to ANSI converter.

Converts file/directory names or text files between unicode and ANSI character sets. Useful, when you want to load files with non-English character names in MS-DOS, as otherwise they are invisible to the DOS system.

Program is able to convert extended ASCII (Czech, German, Polish, Russian and other languages), Korean Hangul, Japanese Hiragana and Katakana into English transliteration.

Note: I am no linguist and the conversion to English transliteration won't be 100% per linguistic rules. However, it should be understandable, the main goal is to allow loading of such files in foreign languages under MS-DOS.

Program works in Windows 2000 and newer. Requires .NET framework 3.5
